# Student Attendance System

## 1. Project Overview

The **Student Attendance System** is a Python project for beginners. It stores details about students. Keeps track of their attendance. Students can be added, records can be viewed attendance can be marked and attendance percentage can be calculated.

## 2. Objectives

* Store each students roll number and name.

* Record days when a Student is present or absent.

* View records for Students and their attendance.

* Compute the attendance percentage for each Student.

* Practice basic Python programming skills.

## 3. Features

The program provides five options:

1. **Add Student**. Adds a Student’s roll number and name.

2. **View Students**. Shows information for all Students.

3. **Mark Attendance**. Marks a Student, as present or absent.

4. **View Attendance**. Displays attendance. Percentage.

5. **Exit**. Ends the program.

## 4. How It Works

The program shows a menu and waits for the users choice. It then carries out the chosen operation using Python lists, dictionaries, loops and if statements.

Attendance percentage is calculated as:

```text

(Present Days / Total Days) × 100

```

The program keeps running until the user picks Exit.

## 5. How to Run

1. Install Python 3.

2.. Clone the repository.

3. Open the project in a Python editor.

4. Run the file `student_attendance.py`.

## 6. Limitations

* Data disappears when the program closes.

* There is no database or permanent storage.

* Attendance is not recorded by date.

* The program does not stop duplicate roll numbers.

* The program uses a command-line interface.
